Motus is an A.I powered tool that provides hashtag and song recommendations based on the audience and caption of the user’s Instagram Post. 
Instagram is a social media platform that offers a wide range of features from short-formed videos, namely Reels,  to stand-still posts. 
There are individuals who act as influencers where they seek to reach as many people as possible to promote a lifestyle or advice. An obstacle that 
influencers may face is having the most choosing the most optimal components to their content, including songs and hashtags. 
Motus bridges this gap by providing trendy song and hashtag recommendations that complement an influencer’s video. 

Motus is a web engine that requests the user to input their target audience or video topic. 
A user can choose to type in their target audience or choose any (or all) of the three given options Gen-Z, Fashion, or Lifestyle. After this input, 
the user then inputs their caption which provides further detail on their video/post content. The utilizes the ChatGPT API and provides recommendations 
based on the specific prompt made as well as the array of information/data OpenAI has access to. The output would then produce 12 different hashtags, but 
it’s recommended to only use 3-5, as well as 5 different trendy songs of that period. This would include specifying if it should be a sped up, slowed down, or 
remixed version, and include the title and artist.
